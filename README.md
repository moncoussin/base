# 🛏️ Mon-Coussin – Soulager naturellement les douleurs liées à l’assise

Bienvenue dans ce dépôt GitHub de [notre boutique en ligne](https://mon-coussin.com), une boutique en ligne française spécialisée dans les **coussins ergonomiques** pour améliorer le confort, la posture et soulager les douleurs chroniques au quotidien.

---

## 🎯 Notre mission

Nous aidons les personnes souffrant de douleurs liées à :
- La **névralgie pudendale**
- La **sciatique**
- Le **coccyx sensible**
- Les **longues assises au bureau ou en voiture**
- Les troubles posturaux liés à la sédentarité

Nos produits sont pensés pour offrir un **soulagement réel**, une **utilisation quotidienne** durable, et une esthétique **sobre et moderne**.
